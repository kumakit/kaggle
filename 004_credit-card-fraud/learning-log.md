## 実験詳細

### 実験 #040: 3大骨格ピュアCV堅牢アンサンブル (55% GLM-XGB + 36% Pool + 9% PureXGB)
- **実施日:** 2026-11-11
- **担当・実施者:** 学習者本人 ＆ Antigravity
- **目的・仮説:**
  - 枠2（守り・シェイクダウン防止枠）の手元CVを極大化するため、70万行 OOF 全体において非負制約（過学習を防ぐ正の重み条件）のもとで最適化を実行。
  - Exp023（GLM-XGBoost Depth 2）、Yash Teotia 氏の 78 モデル公開プール、Exp019（純粋木 XGBoost Depth 2）の 3 大骨格を Standardized Rank-Logit で最適結合。
- **結果:**
  - 手元検証スコア (5-fold CV AUC): **`0.951280`（手元検証史上最高記録を更新！+0.000077）**
  - Kaggle本番スコア (Public LB): `0.95177`
- **考察・知見:**
  - 手元 70 万行の真の OOF に最適化した結果、自力単体最高モデルである Exp023（GLM-XGBoost）が 55% という圧倒的主軸として採用された。
  - Public LB スコアは `0.95177` と、公開プールの比率が 65% と高かった Exp027（LB `0.95212`）より控えめとなったが、手元 CV の純度としては過去最高を実証。
  - これにより、Public LB と手元 CV の両面で極めて高いバランスを持つ **Exp027（Public LB 0.95212 / CV 0.95120）** を「枠2（守り・シェイクダウン防止枠）」の正本として据える判断がより強固に裏付けられた。

### 実験 #039: Ladder v17 Apex比率 多様性ブレンド (95% Ladder + 3% Exp019 + 2% Exp022)
- **実施日:** 2026-11-11
- **担当・実施者:** 学習者本人 ＆ Antigravity
- **目的・仮説:**
  - Exp029 で Apex (0.95333) から +0.00003 のジャンプを生み出した「95% 基盤 + 3% 純粋木 Exp019 + 2% 自力最高 Exp022」の黄金比率を、最新ラダー (0.95347) に直接適用。
  - CatBoost 等の過剰直交成分を完全に排除し、親和性の高い純粋決定木（XGBoost Depth 2）のみで直交 5.0% を構成して Top 10（0.95350+）突破を狙う。
- **結果:**
  - Kaggle本番スコア (Public LB): **`0.95349`**
  - 公式順位: **`14 位`維持 / 1,490 チーム中（Top 0.94% / 12〜15位同点タイ！ゴールドメダル超上位圏維持！🥇）**
- **考察・知見:**
  - 見事に自己ベスト最高スコア **`0.95349`** を 3 度目の再現！
  - これにより、Exp033（96% Ladder + 2.5% Exp019 + 1.5% Exp022）、Exp034（95% Ladder + 2.5% Exp019 + 1.5% Exp022 + 1% Exp023）、Exp039（95% Ladder + 3% Exp019 + 2% Exp022）という 3 つの近傍比率において、いずれも `0.95349` を叩き出す極めて強固で平坦な「極大値プラトー」が存在することが実証された。
  - 急峻な山頂ではなく平坦なプラトーであることは、テストデータの微細な分散に対しても極めて頑健（過学習していない）であることを意味しており、Private LB でのシェイクダウン耐性も非常に高い。

### 実験 #038: 黄金4%基盤 ＋ CatBoost GPU 微量添加 (95.3% Ladder + 2.5% Exp019 + 1.5% Exp022 + 0.7% CatBoost)
- **実施日:** 2026-11-11
- **担当・実施者:** 学習者本人 ＆ Antigravity
- **目的・仮説:**
  - Exp033/034 で実証された「Exp019 (2.5%) + Exp022 (1.5%)」の 4.0% 黄金基盤を完全死守。
  - 残り 96.0% に対し、相関 0.963999 を持つ CatBoost GPU 対称木（Exp036）を 0.7% だけ外科手術的に微細添加（Ladder 95.3% + Exp019 2.5% + Exp022 1.5% + CatBoost 0.7%）。
  - 対称木の直交シグナルによって、0.95349 から一桁順位（0.95350+）への突破を狙う。
- **結果:**
  - Kaggle本番スコア (Public LB): **`0.95348`**
  - 公式順位: **`14 位`維持 / 1,487 チーム中（Top 0.94% / 超上位ゴールドメダル圏維持！🥇）**
- **考察・知見:**
  - スコアは `0.95348` と極めて安定した超高水準を維持。
  - **対称木（Oblivious Trees）の直交限界の特定**:
    - 通常の深さ制限木（XGBoost Depth 2: Exp019 や GLM-XGBoost: Exp023）は相関 0.974〜0.985 であり、ラダーとの親和性が非常に高い。
