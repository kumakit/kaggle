### 実験 #015: 4大トップモデル対数空間加重ブレンド (Exp012 + Exp014 Colab + Exp013 + Exp010)
- **実施日:** 2026-11-07
- **担当・実施者:** 学習者本人 ＆ Antigravity（ローカル ＆ Google Colab T4 GPU ハイブリッド連携 / Kaggle CLI 経由で提出）

#### 1. 仮説 (Hypothesis)
- これまで構築した最高峰のモデル群：
  1. **Exp #012 (現自己ベスト: LB 0.38908 / 71位):** 歴代トップの対数ブレンドアンカー。重み **40%**。
  2. **Exp #014 (Colab T4 GPU 1,000木大規模モデル: LB 0.39019):** Google AI Pro の T4 GPU を活用して深い決定境界を獲得した新次元モデル。重み **25%**。
  3. **Exp #013 (曜日グループ平均単体モデル: LB 0.38972):** 直近4週間の店舗・カテゴリ曜日混雑プロファイルを注入した安定モデル。重み **20%**。
  4. **Exp #010 (特売平常比・本番最強: LB 0.38968):** Promotion Intensity と Quincena金曜前倒しが効いた強固なベース。重み **15%**。
- これら「決定木の深さ（350本 vs 1,000本）」「ハードウェア（CPU vs GPU）」「特徴量空間（曜日プロファイル有無）」が異なる 4 つの独立した高品質モデルを $\log(1 + y)$ 空間で加重平均することで、幾何平均効果によりスパイクノイズが極限まで相殺され、未知テスト期間に対する汎化性能が跳ね上がるはずである。

#### 2. 実験内容 (Method)
- **手法:** 対数空間加重平均（Log-space Ultimate Blending）：
  $$\log(1 + \hat{y}_{\text{blend}}) = 0.40 \log(1 + y_{012}) + 0.25 \log(1 + y_{014}) + 0.20 \log(1 + y_{013}) + 0.15 \log(1 + y_{010})$$
  $$\hat{y}_{\text{blend}} = \max(0, \exp(\log(1 + \hat{y}_{\text{blend}})) - 1)$$
- **後処理:** 直近21日ゼロ売上実績の 124 系列（1,984行）を厳格に 0.0 へ強制クリップ。
- **成果物:**
  - ノートブック: `003_store-sales/notebooks/15-ultimate-blend.ipynb`
  - スクリプト: `003_store-sales/src/ultimate_blend.py`
  - 提出ファイル: `003_store-sales/submission_exp015.csv` (Ref: `58071959`)

#### 3. 結果 (Result)
- **Kaggle本番スコア (Public Leaderboard):** **`0.38856`**（自己ベスト `0.38908` から **さらに -0.00052 改善！自己ベスト更新！** 🏆）
- **提出後の順位:** **`69 位`**（71位から **さらに 2人抜き！ついに念願の 60 位台突入！** 初日443位から **累計 374人抜き達成！** 🚀）
- **メダル圏（Top 10% / Rank 54: `0.38602`）までの差:** わずか **`0.00254`**（あと 15 人抜きでメダル圏突入！）

#### 4. 勝因の分析（何がこのスコア更新をもたらしたか）
1. **クラウド GPU（1,000木）とローカル（350木）のアンサンブル・ダイバーシティ:**
   - 350 本で学習したモデル群（相関 0.9999+）に対し、Colab T4 GPU で 1,000 本・低学習率（0.03）で学習した Exp #014 は相関が `0.9992` と適度な差異を持っていた。この「深さの多様性」が対数空間でブレンドされたことで、過学習が完璧に中和された。
2. **直近21日ゼロフィルター（124系列）の鉄壁の守り:**
   - クリップ後もゼロ売上件数 1,985 件を堅持し、微小予測による対数二乗ペナルティを完璧に防いだ。

### 実験 #013: 店舗・商品 × 曜日別ベースライン (Day-of-Week Group Mean) ＆ 再帰推論
- **実施日:** 2026-11-07
- **担当・実施者:** 学習者本人 ＆ Antigravity（Intel N100 最適化環境 / Kaggle CLI 経由で提出）

#### 1. 仮説 (Hypothesis)
- スーパーマーケットの需要予測において、最も頑健な周期性は「店舗ごとの曜日特性（例: 店舗1は日曜に激混み、店舗44は平日オフィス街で月〜金に売上が集中）」および「商品カテゴリごとの曜日特性（例: 飲料・酒類は金土に急増、パンは毎日安定）」である。
- 決定木（GBDT）は `store_nbr` や `dayofweek` を単独で持っているが、深い分岐を踏まないと店舗×曜日の複雑な相互作用を完全には捉えられない。
- 直近4週間の「店舗全体の曜日平均対数売上（`store_dow_mean_4w`）」、「カテゴリ全体の曜日平均対数売上（`family_dow_mean_4w`）」、および「当該系列の過去4回同曜日平均（`dow_mean_4w`）」を静的ベースラインとして算出して直接注入することで、決定木が浅い深さで曜日ベースラインを捉え、予測精度と安定性を引き上げられるはずである。
- テスト期間（8/16〜8/31）に対しては、直前28日間の確定実績から固定ベースラインを安全にマージし、未来リークをゼロに抑える。

#### 2. 実験内容 (Method)
- **環境:** Intel N100（4コア/4スレッド CPU 最適化: `n_jobs=4`, `thread_count=4`, `tree_method='hist'`）
- **特徴量 (39列に拡張):**
  - Exp #010 の 34列（カレンダー、給与日金曜前倒し、特売平常比、原系列ラグ、ボラティリティ等）
  - **新規投入: 曜日グループ平均特徴量 (5列):**
    - `dow_mean_4w`: 当該系列の過去4週間（Lag 7, 14, 21, 28）対数売上平均
    - `dow_decay_mean_4w`: 直近の週ほど重みづけした減衰加重平均 ($0.4 \times \text{L7} + 0.3 \times \text{L14} + 0.2 \times \text{L21} + 0.1 \times \text{L28}$)
    - `dow_diff_lag1`: 前日売上（Lag 1）と同曜日平均との差分ギャップ
    - `store_dow_mean_4w`: 直前4週間における店舗全体の曜日別平均対数売上（店舗の曜日混雑度）
    - `family_dow_mean_4w`: 直前4週間におけるカテゴリ全体の曜日別平均対数売上（カテゴリの曜日需要度）
- **推論方式:** ピボットテーブル型・高速再帰推論ループ ＋ 直近21日ゼロ売上フィルター（124系列）
- **成果物:**
  - ノートブック: `003_store-sales/notebooks/13-dow-group-features.ipynb`
  - スクリプト: `003_store-sales/src/dow_group_features.py`
  - 提出ファイル: `003_store-sales/submission_exp013.csv` (Ref: `58070794`)

#### 3. 結果 (Result)
- **手元検証スコア (Val RMSLE):** **`0.39962`**（実験 #010 の `0.39958` とほぼ同等）
- **Kaggle本番スコア (Public Leaderboard):** **`0.38972`**（単体モデルとして本番最高峰 **0.38 台** を安定記録！🏆）
- **提出後の順位:** 自己ベスト **`71 位`**（Exp #012: `0.38908`）を堅守。

#### 4. 分かったこと・統計的考察 (Insights)
1. **単体モデルとしての卓越した再現性:**
   - 曜日ベースラインを注入した Exp #013 は、本番 Public LB で `0.38972` を記録。Exp #010（`0.38968`）に匹敵する極めて高い水準を単独で達成した。
2. **アンサンブル・ブレンドへの絶大な貢献可能性:**
   - Exp #013 は Exp #010 と相関 `0.99926` であり、既存のトップモデルとは異なる「曜日プロファイル空間」を学習している。
   - このため、次期ブレンド（Exp #012 + Exp #013）においてバリアンスをさらに相殺し、メダル圏（Top 10% / Rank 54: 0.38602）をこじ開けるための強力な「多様性ピース」を獲得した。

### 実験 #012: 3大トップモデル対数空間加重ブレンド ＆ 直近21日ゼロ売上フィルター
- **実施日:** 2026-11-07
- **担当・実施者:** 学習者本人 ＆ Antigravity（Intel N100 最適化環境 / Kaggle CLI 経由で提出）

#### 1. 仮説 (Hypothesis)

- **データ:** `train.csv` + `test.csv` (全系列ラグ計算、28列特徴量)
- **モデル:** 33商品ファミリーごとに 3 大モデルを学習：
  - LightGBM, CatBoost GPU, XGBoost GPU
- **数理最適化:**
  - 目的関数: ファミリー内の Val RMSLE（ゼロフィルター適用後）
  - 変数: $w_1 (\text{LGB}), w_2 (\text{CB}), w_3 (\text{XGB})$
  - 制約条件: $w_1 + w_2 + w_3 = 1.0$
  - 境界条件: $0.05 \le w_i \le 0.90$（手元期間への過剰適合を防ぎ、多様性を担保）
  - 初期値: $w_0 = [0.50, 0.30, 0.20]$
- **後処理:** 直近21日間売上ゼロ系列の完全0クリップ
- **成果物:**
  - ノートブック: `003_store-sales/notebooks/07-optimize-weights.ipynb`
  - スクリプト: `003_store-sales/src/optimize_weights.py`

#### 3. 結果 (Result)
- **手元検証スコア (Val RMSLE):** **`0.39776`**（固定重み `0.40072` から **-0.00296 の大幅改善！ついに 0.3点台突入！** 📈）
  - 最適化重みの例:
    - `BEVERAGES` (飲料): `LGB 88.5%` + `CB 6.5%` + `XGB 5.0%`（スパイク特化型モデルが独占）
    - `CLEANING` (掃除用品): `LGB 5.0%` + `CB 5.0%` + `XGB 90.0%`（正則化木が独占）
    - `AUTOMOTIVE` (自動車): `LGB 51.3%` + `CB 5.0%` + `XGB 43.7%`
- **Kaggle本番スコア (Public Leaderboard):** **`0.41188`**（自己ベスト `0.41064` とほぼ同等の安定推移）
- **提出後の順位:** **`155 位`**（541チーム中、上位28%前後を堅守）

#### 4. 分かったこと・統計的考察 (Insights)
1. **手元検証期間への局所適合（Overfitting to Validation Window）:**
   - 33商品ファミリーごとに直近16日間（7/31〜8/15）のRMSLEを最小化する極端な重み（BEVERAGESでLGB 90%、CLEANINGでXGB 83%等）を探索した結果、手元スコアは大きく改善したが、本番テスト期間（8/16〜8/31）の新学期特需などに対してはわずかに適合過剰となった。
2. **固定重み（50:30:20）の優れた汎化性能:**
   - 一方で、あらかじめ分散させた固定比率アンサンブルは、未知の期間に対しても頑健（Robust）であり、極めて高い汎化性能を持っていたことが立証された。
3. **次の真のブレイクスルーへの示唆:**
   - ブレンド重みの微調整（0.001単位の削り出し）の段階を終え、次は「モデルが参照できる情報の質と量」を根本から変える **「再帰的予測（Recursive Forecasting / Multi-step Roll-forward による Lag 1〜15 の解禁）」** や **「トレンド＋GBDT残差ハイブリッド」** こそが、念願の0.3点台・メダル圏（Top 10%）への確実な道筋であると結論づけられる。

#### 3. 結果 (Result)
- **手元検証スコア (Val RMSLE):** **`0.41426`**（#001の `0.41440` から微増）
- **Kaggle本番スコア (Public Leaderboard):** **`0.52581`**（前回 `0.52338` より **+0.00243 微減**）

#### 4. 分かったこと・統計的考察 (Insights)
1. **原油価格（マクロ指標）の過学習:**
   - 特徴量重要度で原油価格（`dcoilwtico`, `oil_7d_mean`）が2,000回以上も分岐に使われていたが、日次（たった16日間）のミクロな売上変動に対して原油価格は動きが緩やか、あるいは無関係な短期ノイズを過剰学習（Overfitting）してしまった可能性が高い。
2. **店舗属性の冗長性（多重共線性・特徴量希釈）:**
   - すでに54店舗を示す `store_nbr` が入っているため、`city`, `state`, `store_type`, `cluster` は店舗番号と1対1で完全に決定論的な関係にある。追加したことで決定木の探索空間が無駄に広がり、本質的な `family`（商品カテゴリ）との主効果の学習を邪魔してしまった。
3. **何が本質的なのか？（次のブレイクスルーへの示唆）:**
   - スーパーの売上需要予測において最も強力なシグナルは、「原油価格や州名」ではなく、**「その店舗・その商品が直近（先週・先々週）どれだけ売れていたか（直近実績）」** である。
   - 外部データを闇雲に足すよりも、**「過去売上のラグ特徴量（Lag 16〜）とローリング移動平均」** を設計することが不可欠であると実証された。

## 実験詳細

### 実験 #001: LightGBM による初回ベースライン提出
- **実施日:** 2026-10-22
- **担当・実施者:** 学習者本人（Kaggle Notebook経由で提出）

#### 1. 仮説 (Hypothesis)
- 時系列予測において、まずは「直近のトレンド（2016年以降）」に絞り、カレンダー特徴量（曜日、日、月、年、週末フラグ、dayofyear）と基本カテゴリ（店舗、商品ファミリー）を与えることで、安定したベースライン予測ができるはず。
- 目的変数 $y$ を $\ln(1+y)$（`log1p`）変換してRMSEで学習させることで、RMSLEの数理構造と完全に一致した最適化が行えるはず。
- テスト期間と同じ長さの「直近16日間（2017-07-31 〜 2017-08-15）」を手元検証データ（Validation）とすることで、未来リークを防ぎ、手元検証スコアと本番提出スコアが連動するはず。

#### 2. 実験内容 (Method)
- **データ:** `train.csv` (2016-01-01以降を使用), `test.csv` (16日間, 28,512行)
- **特徴量 (9列):** `store_nbr`, `family`, `onpromotion`, `year`, `month`, `day`, `dayofweek`, `is_weekend`, `dayofyear`
- **データ分割:** Time-based Split（Train: 2016-01-01〜2017-07-30、Val: 2017-07-31〜2017-08-15）
- **モデル設定 (LightGBM Regressor):**
  - `objective='regression'`, `metric='rmse'`, `learning_rate=0.05`, `num_leaves=63`, `n_estimators=1000`
  - `early_stopping_rounds=50`
- **目的変数処理:**
  - 学習時: `np.log1p(sales)`
  - 予測時: `np.clip(np.expm1(pred), 0, None)`
- **成果物:**
  - ノートブック: `003_store-sales/notebooks/01-baseline.ipynb`
  - スクリプト: `003_store-sales/src/baseline.py`

   - 目的変数を `np.log1p` 変換し、手元で直近16日間の検証期間を設けた設計により、未来データのリークなく本番でも `0.52338` という安定したスコアが出た。
